# Wormate.io Configuration

This repository contains configuration files for the Wormate.io game extension.

## Files
- `check.json` - Main configuration file containing game settings, server endpoints, and UI configurations

## About
This configuration file contains:
- Game server endpoints (WebSocket connections)
- UI settings and styling
- Game property definitions (skins, eyes, hats, etc.)
- Regional server configurations

## Usage
This file is used by the Wormate.io game extension to configure:
- Server connections
- User interface elements
- Game customization options

## Security Notice
⚠️ **Important**: This file contains external URLs and WebSocket connections. Use with caution and verify all external domains before use.
